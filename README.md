# 🧪 TaskFlow Mobile — Atividade de QA & Versionamento

Repositório oficial para a execução de testes, auditoria de código, registro de falhas, correções, melhorias e versionamento do aplicativo **TaskFlow**, desenvolvido no contexto da **UC14**.

## 🎯 Contexto do Projeto

O **TaskFlow** foi desenvolvido por uma equipe terceirizada e entregue em versão beta (`0.9.0-beta`). A nova equipe deverá avaliar o produto, registrar falhas, implementar correções e melhorias, organizar versões e preparar o aplicativo para publicação.

## ✨ Funcionalidades Previstas

- Cadastrar tarefas
- Listar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por status
- Definir prioridade
- Persistir dados localmente

## 🛠 Tecnologias Utilizadas

- **React Native**
- **Expo**
- **TypeScript**
- **React Navigation**
- **AsyncStorage**

## ⚙️ Como executar

Acesse o diretório do projeto:
```bash
cd TaskFlow-Mobile

```
Instale as dependências:
```bash
npm install

```

Inicie a aplicação com o Expo:
```bash
npx expo start

```
Depois, execute no emulador Android ou no aplicativo Expo Go.

# 📋 Plano de Ação e Missão da Equipe (QA Cycle)

A execução deste projeto segue o ciclo rigoroso de qualidade de software:

- **Execução e Exploração:** Instalação do ambiente e mapeamento inicial do comportamento do app na versão `0.9.0-beta`.
- **Análise de Requisitos:** Comparação entre o que foi especificado e o que está funcionalmente entregue.
- **Auditoria e Registro de Falhas:** Mapeamento de bugs, falhas de UI/UX ou quebras lógicas, documentando-os com capturas de tela e passos para reprodução.
- **Priorização e Correções:** Implementação de hotfixes, refatoração de componentes e melhorias de estabilidade.
- **Evolução e Versionamento:** Atualização do versionamento semântico (SemVer) rumo à release candidata para publicação oficial.
